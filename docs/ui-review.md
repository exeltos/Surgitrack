# Οπτική ανανέωση: οθόνη-οθόνη

Στόχος: κάθε οθόνη να είναι όμορφη, λειτουργική και μοντέρνα, χωρίς «χοντροκομμένα» σημεία και υπερβολικά βαριά
γράμματα. Περνάμε τις οθόνες με τη σειρά του αριστερού μενού, για τον owner (Studio) και για κάθε ρόλο νοσοκομείου.

## Πώς δουλεύουμε κάθε οθόνη

1. **Στιγμιότυπο τώρα**: `npm run screens -- --role <ΡΟΛΟΣ> --viewport desktop,tablet --only <route>`.
2. **Πρόταση**: τι αλλάζει και γιατί, γραμμένη στον πίνακα παρακάτω.
3. **Απόφαση**: εγκρίνεται, αλλάζει ή απορρίπτεται.
4. **Υλοποίηση**: ένα commit ανά οθόνη, με εικόνα πριν/μετά στη συζήτηση του PR.
5. **Έλεγχος**: `npm run ci` και νέο στιγμιότυπο σε PC και tablet.

Καταστάσεις: ⬜ δεν έχει εξεταστεί · 💬 πρόταση · ✅ έγινε · ➖ καμία αλλαγή.

## Σχεδιαστικές αρχές (η πρόταση για κάθε οθόνη)

Το βέλτιστο για ένα εργαλείο που χρησιμοποιείται όλη μέρα, στο πόδι και με γάντια, είναι **λιγότερα και πιο
σταθερά** στοιχεία. Κάθε οθόνη ελέγχεται με αυτούς τους κανόνες.

**1. Μία οθόνη, μία δουλειά.** Πάνω η κύρια ενέργεια (ένα μόνο βασικό κουμπί, χρώματος), μετά τα φίλτρα, μετά η λίστα.
Ό,τι δεν χρειάζεται κάθε μέρα πάει σε μενού «⋯» ή σε καρτέλα.

**2. Τυπογραφία με τέσσερα μεγέθη.**

| Ρόλος                             | Μέγεθος | Βάρος               |
| --------------------------------- | ------- | ------------------- |
| Τίτλος σελίδας                    | 22px    | 600                 |
| Τίτλος κάρτας / ενότητας          | 15px    | 600                 |
| Κείμενο, γραμμές λίστας           | 13px    | 400 (ονομασίες 600) |
| Βοηθητικό (ετικέτες, ημερομηνίες) | 11.5px  | 500, γκρι           |

Χωρίς βάρη πάνω από 650· χωρίς ΚΕΦΑΛΑΙΑ σε ετικέτες και επικεφαλίδες (τα κεφαλαία διαβάζονται πιο αργά).

**3. Χρώμα μόνο όταν σημαίνει κάτι.** Γκρι = ουδέτερο· πράσινο = έτοιμο/εντάξει· πορτοκαλί = θέλει προσοχή σύντομα·
κόκκινο = πρόβλημα τώρα· το βασικό μπλε-πράσινο μόνο για την κύρια ενέργεια και την επιλογή. Αν όλες οι γραμμές
έχουν την ίδια χρωματιστή ετικέτα, η ετικέτα δεν λέει τίποτα και φεύγει.

**4. Αριθμοί σε μία χαμηλή σειρά.** Κάθε αριθμός-φίλτρο είναι ένα χαμηλό πλακίδιο: εικονίδιο, ετικέτα, αριθμός στην
ίδια γραμμή· πατιέται και φιλτράρει τη λίστα.

**5. Λίστες που διαβάζονται.** Ύψος γραμμής 44–52px (στόχος αφής), η ονομασία έντονη πρώτη, κωδικός/barcode από
κάτω σε μικρό μονόχωρο· οι ενέργειες δεξιά, πάντα στην ίδια θέση· καμία γραμμή κομμένη στη μέση.

**6. Κάρτες με ένα στυλ.** Λευκό, περίγραμμα 1px, γωνίες 12px, χωρίς βαριές σκιές· τίτλος 15px και μία γραμμή
περιγραφής. Κάρτα για ομάδα πληροφοριών, όχι για κάθε στοιχείο.

**7. Κενός χώρος με σκοπό.** Μια σχεδόν άδεια σελίδα δείχνει χρήσιμη άδεια κατάσταση (τι σημαίνει, τι κάνω τώρα)·
μια γεμάτη σελίδα κρύβει τα δευτερεύοντα πίσω από «Περισσότερα».

**8. Ίδια συμπεριφορά σε PC και tablet.** Το μενού γίνεται λεπτή μπάρα στο tablet· τίποτα δεν κόβεται, οι πίνακες
γίνονται κάρτες όταν δεν χωρούν.
