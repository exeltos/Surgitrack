# Οπτική ανανέωση: οθόνη-οθόνη

Στόχος: κάθε οθόνη να είναι όμορφη, λειτουργική και μοντέρνα, χωρίς «χοντροκομμένα» σημεία και υπερβολικά βαριά
γράμματα. Περνάμε τις οθόνες με τη σειρά του αριστερού μενού, για τον owner (Studio) και για κάθε ρόλο νοσοκομείου.

## Πώς δουλεύουμε κάθε οθόνη

1. **Στιγμιότυπο τώρα**: `npm run screens -- --role <ΡΟΛΟΣ> --viewport desktop,tablet --only <route>`.
2. **Πρόταση**: τι αλλάζει και γιατί, γραμμένη στον πίνακα παρακάτω.
3. **Απόφαση**: εγκρίνεται, αλλάζει ή απορρίπτεται.
4. **Υλοποίηση**: ένα commit ανά οθόνη, με εικόνα πριν/μετά στη συζήτηση του PR.
5. **Έλεγχος**: `npm run ci` και νέο στιγμιότυπο σε PC και tablet.

Καταστάσεις: ⬜ δεν έχει εξεταστεί · 💬 πρόταση · ✅ έγινε · ➖ καμία αλλαγή.
