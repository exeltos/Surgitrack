# Marketing — SurgiTrack

Υλικό προβολής του SurgiTrack. Τα βίντεο παρουσίασης δεν βρίσκονται εδώ (είναι πολύ μεγάλα για Git) και φυλάσσονται χωριστά.

## posters/

- `surgitrack_poster12_A2.pdf`: αφίσα A2 (420×594 mm) για εκτύπωση, διανυσματική. Για τυπογραφείο ζητήστε bleed 3 mm και, αν χρειάζεται, μετατροπή σε CMYK.
- `surgitrack_poster12.svg`: επεξεργάσιμο πρωτότυπο (το PDF προκύπτει από αυτό).
- `surgitrack_poster12_preview.png`: προεπισκόπηση.

## linkedin/

- `surgitrack_banner.png / .svg`: εξώφυλλο σελίδας εταιρείας (1128×191 px).
- `surgitrack_cover_personal.png / .svg`: εξώφυλλο προσωπικού προφίλ (1584×396 px).
- `posts.md`: έτοιμες αναρτήσεις (ελληνικά και αγγλικά).

Τα στιγμιότυπα μέσα στα αρχεία είναι από το demo, με κρυμμένα ονόματα προσώπων και εταιρειών.
